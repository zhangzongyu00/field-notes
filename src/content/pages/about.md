这里是 **折腾笔记**，由 [zhangzongyu00](https://github.com/zhangzongyu00) 维护。

记录技术实践、工具发现，以及可以公开分享的工作经验。文章尽量说明问题背景、实际操作、验证结果和适用边界；还没验证的想法会注明。

## 内容如何组织

文章用 Markdown 保存，通过标签关联 iOS、AI、工具和折腾记录等主题。每篇文章保留稳定的地址，后续修正持续更新原文。

博客是完整内容的公开入口。公众号和小红书的版本从同一份母稿和截图整理，内容本身完整可读。平台稿可能调整篇幅、排版或配图，后续更正会先回到母稿。

## 站点如何运行

本站使用 [Astro](https://astro.build/) 和 [AstroPaper](https://github.com/satnaing/astro-paper)，由 GitHub Actions 构建并部署到 GitHub Pages。支持中文搜索、标签、归档、RSS 订阅和明暗模式。

[仓库](https://github.com/zhangzongyu00/field-notes) 保存站点代码、文章和修改历史。主题代码保留原 MIT 许可；文章和截图的使用约定见仓库 README。
